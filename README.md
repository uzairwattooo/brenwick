# Brenwick Website

Responsive, production-ready Brenwick website built from the supplied desktop
and mobile references with semantic HTML, CSS, and vanilla JavaScript.

## Project structure

```text
brenwick-website/
├── index.html
├── article/
│   └── index.html
├── research/
│   └── index.html
├── assets/
│   ├── fonts/
│   │   └── Inter-Regular.woff2
│   ├── icons/
│   └── images/
├── css/
│   ├── article.css
│   ├── research.css
│   └── style.css
└── js/
    └── main.js
```

## Font

The original design uses Borna Medium, which was not supplied. The page uses
the included Inter font as the closest available local fallback, with section
dimensions and responsive line wrapping calibrated to the supplied references.

## Run

Open `index.html` directly in a browser, or serve the folder with any static
web server.
"# brenwick"
